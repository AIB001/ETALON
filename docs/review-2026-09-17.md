## 结论与创新定位

当前合理定位仍是：**在可组合的 CADD 协议上，用可审计的证据准入约束分子–endpoint 主动学习，
再用完整、限额的试验反馈选择有限协议编辑**。MolCascade 单组件和重新设计的 cascade 均可作为执行底座，
不是必须逐层通过默认漏斗。

这次迭代集中修复这一定位所依赖的真实工程漏洞：旧快照能否执行、预算是否严格、结果是否来自指定协议、
失败能否偷渡成训练标签、模型导出是否真能被下游消费。KG、UCB、EI、随机森林、固定面板留一评分和组件编排本身
不是新算法。与已发表工作的关系见 [研究定位](research-innovation-2026-09-17.md)；
当前模块与控制边界见 [架构说明](architecture-current.md)。

本次 40 组小型合成消融中，`decision_aware` 与 UCB 的平均推荐 regret 相同；
因此不能把新增保护机制写成“已证明发现更好的药物”或“已优于 published agents”。
下一步科学验证应使用独立终局分子/协议或外部靶点，统计失败成本与规划耗时，并保留简单基线和负结果。

## 主要修改

| 边界 | 原问题 / 风险 | 当前处理 |
| --- | --- | --- |

| 协议身份 | 同 endpoint 多个 pending proposal 归属不清；未绑定实现的历史运行可被补盖指纹 | proposal 对 endpoint 的占用互斥；相同正文幂等；运行后禁止追认缺失的资源绑定 |
| 执行与文件 | 路径越界、别名、资源改变、重复身份和部分 recipe 完成可造成错误归属 | dispatch 前重核身份/资源；完整要求的 recipe 才能成功；重复/冲突 parent 拒绝；异常保留来源并按预约保守记账 |
| 昂贵阶段 | run 目录可被不当复用；脚本/拓扑变化；超时残留能量可被当作结果 | 输入、参数、环境和关键产物 digest 比对；同 run 排他协作锁；受控进程组；pending/失败记录与显式恢复；非成功 drive 的能量不作为昂贵标签 |

| 分组与表征 | 无环分子按行号分组；同维度不同 Morgan/descriptor 配置可被改名导出 | 无环分子按 canonical SMILES 保持等价分子同组；训练/预测/导出保留完整 representation 身份 |

## 有意改变的兼容性

1. 不再接受 `True` 作为成本/次数、字符串数字、非有限数值、隐式 truthy 的 admission flags。
2. 旧计划被并发提交淘汰后必须重新 plan；运行中的 round 不自动当作已死。
   恢复闲置 round 使用 `recover_idle_rounds(reason=...)`，且先确认 worker 已停止、pending action 已明确处理。
3. 公共 PRISM reuse/drive 要求关键产物 digests；旧 manifest 缺少这些字段时需要明确重建，不能自动补证据。
4. 超时、非零 exit、中断或残留后台子进程不再是整体成功。部分完成产物保留，不能据此进入昂贵标签训练。
   需要重试时必须先核实旧计算已停止，再明确确认 recovery 与理由；不是自动重试。
5. 人工构造的 `Features` 仍可用于内存拟合；要导出 bundle 必须有可信的完整 representation 身份。
   覆盖旧 bundle 只处理已知完整结构，备份路径通过结果返回，未知额外文件或 symlink 不会被递归抹除。
6. 旧模型/控制器指纹不同或历史运行未绑定实现的 benchmark 不能继续冒充当前实现；使用新 workspace。

## 仍未解决、不能由本轮测试证明的部分

- 单 target、小规模 exact GP 和有限预授权编辑空间；不是任意 DAG 自主学习或跨靶点迁移系统。
- live infrastructure 依赖完整 checkout 与 editable 安装；普通 wheel 不包含 vendored assets，尚非独立部署包。
- posterior SD、留一面板分数和旧 conformal 小样本有限截断不自动构成频率覆盖或独立终局科学验证。
- 未部署认证/隔离服务。具名 waiver 与显式 promote 是可审计 API 契约，不是技术上仅人类可调用的边界。
- 资源在有限检查点核验，未建立不可变文件快照；PRISM 三个关键产物 digest 不覆盖所有 force-field include 闭包。
- 进程清理限于本地 POSIX 自建进程组；脱离 session 的 daemon、远程 scheduler 和非 POSIX 平台需要专用 adapter。
- 成本报价不是运行费用上界；异常时可能只知道预约成本而不知道实际费用。不得把 conservative charge 写成测得的 GPU 小时。
- 新 SQLite 与旧 JSONL 路径仍分离；后者的合作式文件锁不等于完整科学执行的 write-ahead 事务，也不防不合作外部编辑。
- replay 初始化虽已前置校验，但配置、资源绑定、候选写入与 imports 不是一笔总事务；进程崩溃后须依靠相同 manifest 的幂等恢复。
- 源码指纹 + 少量库版本不是完整容器/BLAS/硬件环境锁，也不是对正在运行 code object 的远程证明。
- 没有完成真实 prospective CADD、wet-lab 或与 published agents 的同任务独立对照。
