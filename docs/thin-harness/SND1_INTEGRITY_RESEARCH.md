# A complete, optional SND1 research example

`examples/snd1_integrity_research.py` connects existing research interfaces; it
does not launch a solver, install a mandatory phase, change a global default,
or run an autonomous scientific judge. The host selects the question and makes
the final, scoped adoption decision.

The companion controlled-ablation example supplies an immutable protocol,
selection and execution freeze. `prepare` authenticates them, records a method
revision/opportunity and evaluation plan, then creates a checkpoint. The four
numeric rules come from the frozen scientific protocol. A saved preparation
cannot relax those rules or substitute another original.

`complete` consumes the native receipt, derived metrics, original factorial
comparison, and interruption evidence. It rechecks the receipt's freeze and
artifact inventory, the metrics' transitive originals, frozen denominators,
integer count bounds and consistency with the authenticated comparison.
Cached completion performs these checks again before returning. A mutable
summary cannot substitute a different run or make a missing required check
pass. The general evaluation-contract API checks the declared rules; it does
not certify that an objective or verifier establishes scientific truth.

The existing method-use, research-step, evaluation, resolution, claim,
experience and opportunity-disposition records preserve their exact links.
The counter record contains all four cells, including zero benefit from an
ablation and the measured cost. A host may adopt only within the frozen scope;
`default_changed` remains false. Retrieval matches declared conditions, not
undeclared similarity. In particular, an identical protocol hash alone does
not justify transfer to new starting coordinates or another selected panel.

Publication uses the existing isolated, resumable publication interface. It
never retries scientific execution. `audit` resumes the published checkpoint,
recovers the same terminal opportunity, reads the scoped experience, and
requires no new journal events. Controller/native process recovery is a
separate optional adapter; its receipt is evidence, not another scientific
charge. Missing process identity remains unknown and does not authorize a
retry.

```text
python examples/snd1_integrity_research.py prepare --root ARCHIVE --protocol RUN/protocol.json
python examples/snd1_integrity_research.py complete --root ARCHIVE --summary METRICS --receipt RECEIPT --recovery RECOVERY --comparison COMPARISON --outcome retain
python examples/snd1_integrity_research.py prepare-publication --root ARCHIVE
python examples/snd1_integrity_research.py resume-publication --root ARCHIVE
python examples/snd1_integrity_research.py audit --root ARCHIVE
```

The example is for the SND1 frozen, seen, near-crystal repair task. The historical
seed split is retained but is not an independent holdout. Crystal-derived
initialization and positional anchors remain available. A passing result
establishes neither blind pose prediction, affinity accuracy, workflow-wide
speedup nor independent chemical transfer. Threshold declarations in verified
historical artifacts provide audit evidence; the generic evaluation report
does not independently notarize their chronology.

Read a continuation in bounded stages: current checkpoint and reference index,
then exact originals required by the decision. An excerpt or scoped reference
coverage receipt is not a full-history audit. Preserve explicit incomplete
coverage when a context budget cannot include every counter excerpt. Full
original and counter checks remain available through the existing evidence
reader, graph scope and handoff APIs.

Tests use labelled temporary fixtures. They verify changed identities, mismatched
metrics, missing checks and completion/publication replay, without running
molecular calculations. Real scientific execution, process interruption,
publication interruption, native host compaction and remote handoff evidence
are distinct integration receipts and must not be inferred from those tests.
