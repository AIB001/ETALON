# Optional empirical-gap branch confirmation example

`examples/research_branch_confirmation.py` is a bounded scientific experiment,
not a scheduler, global router or default policy. It uses an explicit run root,
fixed imported scientific implementations and immutable task source snapshots.
It reuses the existing pose-task compiler, native engine, request/receipt cache,
same-pool checks, result-integrity contract and fixed-frame symmetry RMSD.

The candidate purchases fixed CNN rescoring when the empirical top-two score gap
is at most 0.5 kcal/mol. The threshold was informed by already-seen cases. The new
24-case confirmation fixes seven PB308 and seventeen Astex cases after declared
historical-series exclusions and target-CCD atom checks, including hydrogen.
Model-training overlap and remote homology remain unknown. Gold coordinates are
restricted to the verifier; the known pocket centroid is conditioning input.

The full experiment executes CNN on every successful pool for paired controls.
Measured per-branch cost permits policy attribution, but this audit physically
avoids zero CNN calls. Native execution, unknown/failure, verifier cost and
unmeasured overhead must remain separate. An empirical energy gap is not a
calibrated uncertainty probability.

Rules, inputs and source imports are frozen before execution. Per-case physical
validity regressions cannot be offset by gains in other cases. The existing
method revision/evaluation/resolution/conditioned-experience/terminal APIs record
the scoped result; a repeated read does not justify re-execution. The task-local
RSI base method is the always-CNN experimental cost comparator, not a deployment
change. No result silently changes the default baseline.

The actual source/data hashes, two-stage pre-execution review, source strata,
negative evidence, receipts and final decision live in the controller's explicit
`integration/etalon-default-research-20261025/science/` evidence package. Follow
that package's final entry and report rather than treating this example's
existence as scientific validation or general adoption.
