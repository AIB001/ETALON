# 下一阶段：让 ETALON 的研究主张可以被否证

这是候选预注册方案，**尚未冻结数据、运行实验或建立科学优效性**。
它承接 [本轮检查](review-2026-09-17.md)、[研究定位](research-innovation-2026-09-17.md)
与 [当前架构](architecture-current.md)，不把既有 KG、LinUCB 或 EI 改名当作创新。

## 为什么现有 smoke benchmark 不够

本轮 40-run `synthetic-v1` 中，UCB、MF-KG、`decision_aware` 及三个 decision 消融在全部五个 seed
上选出相同的最终候选，推荐 regret 均相同；`local/global/none` 的平均总支出与 invalid 支出也相同。
所有组都保留硬 QC；端点只有固定的 proxy/reference；proxy 失效按候选索引 `% 5` 定义，
没有预设与分子特征的关系；没有运行外层协议搜索。因此它不能识别下列机制的独立贡献。

## 1. 先冻结独立评价单位

每个靶点分开保留：协议搜索面板、独立协议验证面板、最终分子选择池。
按 scaffold 隔离，相关 assay 批次和受体状态不跨训练/测试混用。
协议目录、超参数与成本换算只在开发靶点选择；验证靶点和终局标签在冻结前不得进入选择流程。
对于当前单靶点控制器，“留靶点评价”指独立启动每个 campaign，**不是已经实现跨靶点训练/迁移**。

主要终点：固定总预算下的 evidence-backed recommendation regret；同时报告 provisional regret、
无合格推荐比例、确认查询数和不确定的费用。只有完整且协议一致的隐藏参考池才能计算全池 regret。
真实实验未测全时改报预先定义的确认命中率，不能把未测值补零或当失败。
使用靶点级配对差值评价泛化；增加 seed 不能替代增加独立靶点。

## 2. 有限协议学习是否值得付开发成本

保持相同授权 variant 目录、内层分子策略、审计面板预算和显式晋升规则，对照：

- 固定原协议，不搜索。
- 随机选择允许的 variant。
- 共享编辑特征的 LinUCB（当前外层基线）。
- one-hot variant 特征的 LinUCB（不共享编辑经验）。

先不开经济停止；初始化、完整协议试验及后续分子查询都计入同一总预算。
独立验证面板不能反向参与搜索；最终候选池不能用于事后挑 variant。

**否证条件：** 只改善搜索面板 `panel_skill`，不能改善独立验证或终局推荐；
或把协议开发成本计入后收益消失。这项比较不在当前 40-run 报告中。

## 3. 硬证据准入是否优于单纯少用标签

只在隔离的离线影子模型中使用同一批已取得记录，对比严格准入、忽略数值型 QC 的训练、
随机丢弃同样数量的标签。始终保留身份/单位约束，并使用相同严格标准定义终端 evidence-backed 推荐。
无准入影子模型不得用于 live campaign 或协议 promotion。

先固定查询序列以分离训练标签筛选的作用，再与“固定/学习协议”交叉，检验交互收益。
QC 真值必须来自独立盲审或事先固定的故障注入，而不是由模型预测误差反向定义。

**否证条件：** 严格准入不优于随机等量丢弃；或效应仅由更少训练标签、不同预算/评价规则造成。
当前所有策略都保留硬 QC，不能从其比较估计这项效应。

## 4. 条件准入与确认预算保护能否被区分

冻结 `none/global/local × guard off/on` 六组，全部保持硬 QC；预先声明无失效、随机失效、
分子特征条件失效、与潜在目标相关的失效四种情境，以及紧预算和宽预算档位。
紧预算应确实出现只剩一次 objective 确认机会的状态。

分别评估 invalid 支出、独立随机审计样本上的准入概率校准、未确认推荐比例与终局 regret。
用于校准评价的审计样本不能只由当前 acquisition 选择，否则再次混入选择偏差。

**否证条件：** local 不优于 global；或 guard 只减少支出却恶化终局推荐。
不能用随机失效任务的胜负替代对条件学习机制的检验，也不能事后只留下获胜 seed。

## 5. 外层停止是否改善整个 campaign

比较 `audit_ei`、相同 ranking 但不停、无协议搜索；冻结全部 λ 与预算档位，不按终局结果选择 λ。
停止后释放的预算允许用于内层 objective 确认，而不是只报告“省了多少协议查询”。
记录执行失败、QC 拒绝、重试、完整审计面板和规划耗时；未知成本报告区间或缺失，不能补零。

主要结果仍是终局推荐 regret；辅以总费用、遗漏优质 variant、提前停止风险和规划 wall time。
若要报告净效用，另行预声明“最终目标效用↔费用”换算；不能直接复用当前 `panel_skill↔cost` 的 λ。

**否证条件：** 节省费用伴随事先规定为不可接受的推荐退化；或省下预算并未增加终局决策价值。

## 启动下一阶段前应冻结的清单

数据许可与目标定义、去重/身份规则、scaffold/target/batch split、隐藏参考覆盖率、
协议目录和人工晋升规则、QC 真值来源、全部策略/超参数/预算档、主要终点及失败处理、
成本记录方式、统计评价单位、代码/环境身份和排除规则。

目前缺少的核心证据是**独立数据上的机制增益**，不是更多名称不同但难以消融的 agent 角色。
工程完整性是开展这些实验的前提，不是实验的结论。
