# An advisor with separate working memory

When an independent advisor is requested, start it with a fresh context, the
scientific objective and selected facts. Do not copy the full main transcript.
Give it its own entry, active methods/skills and native host delivery state.

Use `etalon_research_fork_memory(entry, destination, memory_scope, question)` or
`python -m etalon research fork-memory --entry MAIN --destination ADVISOR
--scope advisor-performance --question "Which change would improve this task?"`.
This creates one ordinary note in the same research journal. Original artifacts
are shared by reference. Source `shared_entry` and `shared_basis` are explicit;
the main plan, hypotheses and entire skill set are not copied. Retrying reuses the
existing advisor entry and its later progress.

Write advice with the ordinary progress interface against ADVISOR. Default
`find_notes` searches shared memory; private retrieval explicitly supplies
`memory_scope`. The advisor's entry catalog exposes only its own branch heads.
This is working-memory separation, not an access-control boundary. Filesystem
access and any host-global automatic memory need their own host configuration.
Bind hooks to ADVISOR, not MAIN; never install a second hook over the main binding.

Inspect new throughput/reuse differences, unexpected attrition, conflicting
scientific readouts or a meaningful failure. Shared result references and negative
evidence stay readable. Avoid re-reading the archive and duplicate wait loops.
No new actionable difference means no advisory message. A rejected hypothesis
needs new conditions or evidence before being proposed again.

Advice can contain the observation, a possible explanation, the smallest useful
alternative action, expected cost, and whether it should affect current or future
work. Put unresolved ideas in private memory. Send only relevant advice to the
main host, which chooses a trial, adoption, deferral, retention or no change.
Do not reinterpret a rejected suggestion as a disproved scientific claim.

Use existing opportunity identities when applicable; a short note suffices for
ordinary work. The main host publishes an adopted method/lesson through its own
progress entry with a reference to the advice. Measured counterevidence belongs
in shared science even when the proposed policy is rejected. No automatic draft
merge, no per-batch judge, no fixed Probe, and no automatic job interruption.

On a new chat, resume the correct entry and native handles. Evaluate an advisor
by useful decisions and complete research cost including its own model calls,
not by review frequency or the number of proposed skills.
